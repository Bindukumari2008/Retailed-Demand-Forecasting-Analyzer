Machine Learning Methodology

  • Algorithm: Random Forest Regressor (Ensemble of Decision Trees).
  • Split Strategy: Strict Chronological Time-Series Split (80% Train, 20% Test).
  • Leakage Prevention: Lag features (lag_1, lag_7, lag_14) and rolling statistics (rolling_mean_7, rolling_mean_14, rolling_mean_30) use strictly shifted historical windows (shift(1)).
  • Evaluation Metrics: MAE, MSE, RMSE, R² Score, and MAPE.
